# Tiến độ 5 tuần (checkpoints theo đề bài)

- **Tuần 1:** Đề tài, nguồn dataset, 1–2 trang formulation, pipeline, README khung, repo public.
- **Tuần 2:** Tiền xử lý, baseline, bảng kết quả, environment/requirements, notebook v1, commit.
- **Tuần 3:** Random Search với log từng trial, feasibility, convergence plot, source, cập nhật README.
- **Tuần 4:** Chạy đủ thực nghiệm, sensitivity và stability, CSV/JSON, 2+ hình, so sánh runtime, Key Results.
- **Tuần 5:** Chốt lựa chọn, báo cáo 8–12 trang, 5–8 slide, demo 5–7 phút, link GitHub, release/tag v1.0.

**Lưu ý:** Bộ file được tạo và chạy tại cùng một thời điểm để hỗ trợ triển khai, không phải bằng chứng đã học/làm qua 5 tuần. Lịch sử commit thực tế phải được tạo trong quá trình bạn tự thực hiện và kiểm chứng.
