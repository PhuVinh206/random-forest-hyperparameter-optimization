Dataset: Breast Cancer Wisconsin (Diagnostic), accessed through scikit-learn load_breast_cancer(). No raw patient-identifying data is stored in this repository.
Information and citation: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html
Data: 569 samples; 30 numeric predictors; two classes. Documentation includes the original dataset reference.
The data is accessed programmatically; no external download, token, or local CSV is required.
